一、WiFi：连接与信号那些事

  • 连接：任务栏右下角 WiFi 图标 → 选网络 → 输密码。已连过的自动连。
  • 忘记网络重连：设置 → 网络和 Internet → WiFi → 管理已知网络 → 忘记，再连。
  • 2.4GHz vs 5GHz：5GHz 快但穿墙弱；2.4GHz 慢些但远。路由器开启"双频合一"交给它自动选最优。
  • 信号差：把路由器放高、少隔墙；大户型上 Mesh/电力猫；别把路由器塞进弱电箱闷着。
💡 用"以太网"看型号 路由器背后贴纸有管理地址（如 192.168.1.1）和默认密码，浏览器访问即可进后台（改密码/管理设备）。第一次用时务必改掉默认管理员密码！

二、网线直连：更快更稳

台式机/笔记本插上网线（RJ45 水晶头），Windows 会自动识别"以太网"。网线直连的优势：无无线干扰、延迟低、不会被邻居蹭网。游戏/直播/拷贝大文件用网线是首选。

三、手机热点与共享网络

  • 电脑连手机热点：手机"个人热点"打开 → 电脑连该 WiFi（注意流量）。
  • 有线共享：USB 数据线连接手机 → 手机提示"USB 网络共享"→ 电脑立即上网，比 WiFi 热点稳得多。
  • 紧急断网但有多台设备：用手机的"WiFi 直连"或蓝牙共享救急。

四、测速与"明明100M为什么慢"

打开测速网站（如 speedtest.cn，或运营商官方测速）测下载/上传/延迟。拿到结果先对照：

现象常见原因对策
下载远低于带宽/8WiFi 信号弱、网线老化、路由器太老靠近路由器测、换线、换千兆路由器
看视频卡、网页慢DNS 慢、后台下载占满、多人共享改 DNS（§5）、暂停后台、错峰
延迟高（打游戏）无线干扰、跨省/跨国节点远换网线、选区服、用加速器（合规场景）
⚠️ 测速的讲究 用同一网站、同一时间段、贴近路由器、电脑不跑下载任务时测，才有可比性。不同时段运营商拥塞差别很大。

五、改 DNS：提速与护网

DNS 是"网址翻译官"：把 baidu.com 翻成 IP。运营商 DNS 可能慢或被污染，换成公共 DNS 常能提速：

国内常用：114.114.114.114（114DNS）、223.5.5.5（阿里）
全球通用：1.1.1.1（Cloudflare）、8.8.8.8（Google）

修改方法：设置 → 网络和 Internet → 当前网络属性 → DNS 服务器分配 → 手动 → 填首选/备用。改完 ipconfig /flushdns（见 F 模块命令）刷新缓存。

💡 什么时候改 网页能开但特别慢、换个域名反而快、上不去的站换 DNS 却通了——这都值得试。改完不行就改回"自动（DHCP）"。

六、断网了？两分钟排查

  1. 看任务栏图标：红色 x = 网线没插/驱动问题；黄色感叹号 = 连上了但没外网（先查路由器）。
  2. 先断后连：WiFi 开关切换一次，或拔插网线。重启电脑/路由器（拔电源等 30 秒再插）能救 80% 的怪问题。
  3. 让系统诊断：右键右下角网络图标 → 诊断。让它自己修复。
  4. 命令三板斧：Win+R 输 cmd 回车，依次运行 ipconfig /release → ipconfig /renew → ipconfig /flushdns。
  5. 仍然不行：手机开热点试电脑——热点能上则问题在路由器/宽带；热点也上不了则问题在电脑网卡或系统。
