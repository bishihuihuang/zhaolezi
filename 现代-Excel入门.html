一、Excel 是什么

Excel 是微软 Office 里的"表格软件"（免费替代是 WPS 表格）。它是一张巨大的网格纸，能放文字、数字，还能自动计算：记个家庭账本、做个通讯录、列一张购物清单，用它最合适。

💡 什么时候用 Excel？ 有规律的数据就用表格：账目、名单、时间表、统计数字。一列一列排整齐，还能自动算总和——比手写账本省心一万倍。

二、认识表格：行、列、单元格

打开 Excel，看到满屏的格子：

概念长什么样打个比方
列竖着的格子（顶部是 A、B、C…）房间的一排柜子
行横着的格子（左边是 1、2、3…）柜子的一层搁板
单元格一个格子，地址用"列+行"表示柜子里的一个格口
活动单元格当前选中的格子（有粗边框）你正打开的那个格口

操作要领：点哪个格子，字就输进哪个格子。比如点 B2（B 列第 2 行），再打字，内容就进 B2 了。输完按 Enter 跳到下一格，按 Tab 跳到右边一格。

三、输入数据与自动求和

做个买菜清单

  1. A1 输入"项目"，B1 输入"金额"（这是表头，说明每列是什么）。
  2. 往下填：A2"猪肉"、B2"35"；A3"鸡蛋"、B3"18"；A4"青菜"、B4"8"……
  3. 点 A5 输入"合计"，再点 B5。
  4. 点顶部工具栏的「Σ 自动求和」（或按住 B2 拖到 B4 选中后点 Σ）→ 回车。
  5. B5 立刻显示总和——数字改了，总和自动跟着变。
🧠 Excel 的魔法：公式 求和用的是"公式"（=SUM(B2:B4)）。你不需要懂公式，只要记住：想算总和，点 Σ 自动求和，Excel 帮你干最烦的算术。

四、排序：让数据排排队

想把通讯录按名字排、把账目按金额排？选中数据 → 点工具栏「排序」→ 选"升序/降序"：

  • 升序：从小到大（数字 1→9，日期从前到后）。
  • 降序：从大到小。
  • 按谁排：排序前先点表头那一列（比如"金额"），Excel 知道按哪列排。
⚠️ 排序前先选中全部数据 只点一列排序，其他列不跟着动，表格就"错位"了。正确做法：选中整个数据区域（表头+所有行）再排序，让每一行整整齐齐一起动。

五、生活中的用途

用途怎么做
家庭账本三列表：日期 / 项目 / 金额，每月底自动求和，月底对账一目了然
通讯录四列表：姓名 / 电话 / 住址 / 备注；按姓名排序好查
吃药提醒表列表：药名 / 每天几次 / 每次几片 / 注意事项，打印出来贴冰箱
旅行计划列表：日期 / 行程 / 住宿 / 花费预算
同学聚会名单列表：姓名 / 是否参加 / 联系电话，统计"参加人数"用求和或数数
💡 打印表格 做好表格想打出来：点「文件 → 打印」，先预览看看排版，再点打印（K4 课细讲打印设置）。

本页小结

  • Excel 是"电子账本"：点哪个格子，字进哪个格子；顶部 A/B/C 是列，左边 1/2/3 是行。
  • 算总和：点「Σ 自动求和」，数字变了总和自动更新。
  • 排序要选中整个数据区域，防止表格错位。
  • 家庭账本、通讯录、吃药表都是 Excel 的好用武之地。
