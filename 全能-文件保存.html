📖 网页使用指南
  • 添加：填写标题（可选）+ 内容 + 标签 → 点击「保存条目」；也可「📎 选择文件」文本与文件一并保存；⛶ 可全屏编辑
  • 查找：支持关键词 / 时间（如 2026.9）/ 状态词筛选，顶部标签可组合；Ctrl+F 快速聚焦
  • 命令面板：按 Ctrl+K（或左上角按钮）打开，输入即过滤、↑↓ 选择、回车执行，可直达任意条目
  • 时间范围：统计栏下方胶囊可切换到 今天 / 本周 / 本月 / 全年，指标数字随之滚动重算
  • 状态：条目的「切换为…」可在 重要 / 次要 / 待办 间循环；⭐ 可置顶
  • 文件：文件条目显示 📎 文件名与大小，可「预览」「下载」（图片/文本等17种格式内联预览）
  • 编辑：修改（原位）/ 大屏修改（抽屉）/ 复制 / 复制完整条目
  • 批量：开启批量模式后勾选，可批量设状态、置顶、删除
  • 回收站：删除先入回收站，可恢复或清空
  • 导出导入：TXT / MD / JSON 导出；TXT 导入（追加合并 / 替换全部）
  • 主题：右上角按钮切换 深色 / 亮色 / 米黄 / 黑金 / 国风 / 巨物巨构 / 风雪高山 / 自定义（自由配置）
