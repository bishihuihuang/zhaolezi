一、软件是什么

A1 里讲过：计算机 = 硬件 + 软件。软件（Software）就是运行在硬件上的指令集合——它摸不到、没实体，但决定了硬件做什么。按用途分两大类：

类别作用例子
系统软件管理硬件、给其他软件打地基Windows、macOS、Linux、Android、iOS
应用软件完成具体任务微信、浏览器、Word、游戏、视频播放器
💡 一句话理解 操作系统是"物业公司"，应用软件是"租户"。租户（微信、浏览器）都要通过物业（操作系统）使用楼里的水电（CPU、内存、硬盘）。

二、操作系统的四大职责

操作系统（OS，Operating System）是开机后第一个运行的"总管家"。一台电脑为何能同时开着浏览器、听歌、打字？全靠它：

  • 管硬件（进程调度）：把 CPU 时间、内存、磁盘公平地分给每个运行中的程序（叫"进程"），谁也别想独占。
  • 管文件：把磁盘上亿万个存储单元组织成你熟悉的"文件夹"结构，还负责权限与回收站。
  • 管界面：把鼠标点击、键盘输入翻译给程序，把程序输出画到屏幕上（图形界面 GUI）。
  • 管安全：隔离不同程序的权限，防止一个程序乱改另一个程序的数据，这是安全的第一道防线。
🔍 眼见为实 按 Ctrl+Shift+Esc 打开任务管理器：列表里每个条目是一个进程，能看到 CPU/内存实时占用——这就是操作系统"管硬件"的直接证据。想深挖见模块B。

四、32 位与 64 位

这说的是 CPU 一次能处理的数据宽度。64 位一次搬 64 bit 数据，并且能认出超过 4GB 的内存；32 位系统最多只能用约 4GB 内存。今天的电脑几乎全是 64 位。

下载软件时常见后缀：x86 = 32 位（历史命名）；x64 / amd64 = 64 位；arm64 = 手机/新 Mac 那类 ARM 架构。普通用户记一条：有新装新，桌面装 x64 即可。

五、驱动程序：翻译官

不同厂商的打印机、显卡、声卡各有各的"方言"——驱动（Driver）是介于操作系统和硬件之间的翻译官，让系统听懂每个零件的话。

  • 大多数常见硬件（鼠标、键盘、U盘）系统自带驱动，插上就能用。
  • 显卡、打印机这类复杂设备需要单独安装：通常去官网下对应型号驱动（别用杂牌"驱动精灵"一类，易捆绑广告）。
  • Windows 里随时可更新驱动：右键"此电脑"→ 管理 → 设备管理器 → 右键设备 → 更新驱动。
  • 典型信号：硬件上有黄色感叹号、突然没声音、分辨率不对——八成是驱动问题，重装/更新驱动可解。

六、"装系统"是什么意思

把操作系统写入硬盘并设置好引导，就叫装系统。重装系统 = 把系统盘清空后重新写入一份干净的 Windows，适用于系统严重损坏、顽固病毒、或想让电脑"焕然一新"的场景。

① 备份：把 C 盘中的文档、照片、浏览器收藏统统拷到别的盘或网盘。这是最重要的步骤！
② 准备启动盘：一个 8GB 以上 U 盘，用微软官方工具（Media Creation Tool）写入 Windows 安装镜像。
③ 从 U 盘启动：插入 U 盘重启，开机时狂按 F12 / F9 / Esc（品牌不同键不同）进入启动菜单，选 U 盘。
④ 走安装向导：选语言 → 选"全新安装"→ 选目标磁盘（看清容量，别选错盘）→ 删除原系统分区后格式化 → 等拷贝重启。
⑤ 收尾：设置账户 → 联网自动更新驱动 → 装常用软件。大功告成。
⚠️ 量力而行 重装会清空目标盘全部数据。第一次操作请在有人指导或详细图文/视频教程下进行；系统只是"卡/慢"时，先试试模块B 的排障流程，多数问题不用重装。
