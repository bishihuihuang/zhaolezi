一、什么叫"托管"

把网站文件放到一台 24 小时在线的机器上并让人能访问，就是托管（Hosting）。本质=处理三件事：存放文件、分配地址（域名/IP）、带宽传输。你不需要自己买服务器，向托管商"租地方"即可。

二、三大托管方式对比

方式适合价格你要做
静态托管平台（GitHub Pages/Netlify/Vercel）纯 HTML/CSS/JS 的静态站常免费上传文件，平台分发 CDN
虚拟主机/空间个人站、企业小站几十元/年FTP 传文件，面板管理
云服务器（自己装环境）动态站、高自定义几十~几百元/月装系统、装 Nginx/程序、维护安全
💡 本站的答案 本站是纯静态站，所以选GitHub Pages：免费、全球 CDN 加速、带 HTTPS 证书，还和学习链（F/G 模块）本地闭环——你即将会亲手发布它。

三、GitHub Pages：免费静态托管

GitHub Pages 是 GitHub 免费提供的静态网站托管：把你仓库里的文件，通过 用户名.github.io/仓库名/ 变成可访问的网站。

  • 1GB 空间、每月 100GB 流量以内全免费，个人/开源项目完全够用。
  • 自动配 HTTPS 证书（地址带锁），每人有 用户名.github.io 这个"个人网盘域名"。
  • 天然和 Git 绑定：代码一推送，网站自动更新（构建发布流水线，F/G 模块实战）。
  • 还能配合 Jekyll 模板、子路径部署、自定义域名。

四、Pages 如何使用（概念版）

  1. 建仓库：GitHub 新建仓库，名字取 仓库名（如 xiandaihua）。
  2. 推代码：把网站根目录文件提交并推送到仓库（F 模块实际操作）。
  3. 开 Pages：仓库 Settings → Pages → 选择分支（main + 根目录）→ Save。
  4. 等 1-2 分钟，访问 https://用户名.github.io/仓库名/，上线！
💡 两种 Pages 地址 仓库名若是 用户名.github.io，网站地址就是根域名（无子路径）；其他仓库名则是 用户名.github.io/仓库名/。本站构建脚本的 SITE_BASE 就是按后者配置的。

五、自定义域名

想用你自己的域名（如 myname.com）替代 xxx.github.io？两步：① 到域名商加一条 DNS 记录（CNAME），指向 用户名.github.io；② 在仓库 Settings → Pages → Custom domain 里填上你的域名，GitHub 会自动签发证书。一般个人站免费托管 + 便宜域名（几十元/年）就够。

六、选型决策表

我的网站是推荐托管理由
个人主页/文档/简历GitHub Pages / Netlify免费 + 秒级上线
带联系表单的小站静态托管 + 表单服务不必买服务器
需要登录/数据库云服务器动态能力自建
公司官网、量大稳定云厂商托管服务SLA 保障 + 售后
🤔 课后思考 既然 GitHub Pages 免费又好用，为什么企业还要花钱买服务器？——因为动态功能、数据库、合规（国内备案）、定制能力它给不了。免费是"够用"，不是"万能"。
