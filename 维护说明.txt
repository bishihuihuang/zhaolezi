========================================
  网站维护说明 - 混淆版网站
========================================

【重要】当前网站已开启防小白保护和JS混淆，
修改网站时请按照以下流程操作，不要直接修改根目录的HTML文件！

========================================
一、文件结构说明
========================================

zhaolezi/
├── index.html          ← 混淆后的首页（线上使用，勿直接修改）
├── 1.html ~ 29.html    ← 混淆后的子页面（线上使用，勿直接修改）
├── _混淆工具.js         ← 混淆脚本（用于重新混淆）
├── _原始未混淆版/       ← 【重要】原始未混淆文件（修改这里！）
│   ├── index.html
│   ├── 1.html ~ 29.html
│   └── ...
├── 维护说明.txt         ← 本文件
└── 其他资源文件（图片、音频等）

========================================
二、修改网站的正确流程（3步）
========================================

第1步：修改原始文件
  打开 _原始未混淆版 文件夹
  修改需要改动的 HTML 文件（用记事本、VS Code等均可）
  保存文件

第2步：运行混淆脚本
  在 zhaolezi 文件夹中打开命令行（PowerShell或CMD）
  运行命令：
      node _混淆工具.js
  等待提示"完成：成功 30 个"

第3步：提交并推送
  运行命令：
      git add .
      git commit -m "修改说明"
      git push origin main
  等待1-2分钟，GitHub Pages自动更新，刷新网页即可看到效果

========================================
三、快速修改命令（一键完成）
========================================

如果只想快速修改并发布，可以在PowerShell中运行：

  cd D:\Administrator\桌面\zhaolezi
  node _混淆工具.js
  git add .
  git commit -m "更新网站"
  git push origin main

========================================
四、恢复原始版本（如需取消混淆）
========================================

如果混淆后出现问题，可以恢复原始未混淆版本：

  cd D:\Administrator\桌面\zhaolezi
  node _混淆工具.js 恢复

这会把 _原始未混淆版 中的文件复制回根目录，覆盖混淆后的版本。

========================================
五、防小白保护功能说明
========================================

已添加的保护功能：
  1. 禁用右键菜单（防止"查看源代码"和"审查元素"）
  2. 禁用 F12 键（开发者工具）
  3. 禁用 Ctrl+Shift+I / Ctrl+Shift+J（开发者工具）
  4. 禁用 Ctrl+U（查看网页源代码）
  5. 禁用 Ctrl+S（保存网页）
  6. 禁用 Ctrl+Shift+C（元素选择器）
  7. JS代码Base64编码混淆（eval解码执行）

注意：这些功能只能防小白，有经验的开发者仍可通过其他方式查看代码。
如果需要更强的保护，建议把核心逻辑放到服务器端。

========================================
六、常见问题
========================================

Q: 为什么不能直接修改根目录的HTML文件？
A: 根目录的HTML文件已经被混淆，代码是Base64编码的，直接修改会导致代码损坏。
   必须修改 _原始未混淆版 中的文件，然后重新混淆。

Q: 修改后网站没有变化？
A: 检查是否完成了3步：修改原始文件 → 运行混淆脚本 → git push。
   另外GitHub Pages更新需要1-2分钟，可以加 ?v=随机数 强制刷新缓存。

Q: 混淆后网站功能异常？
A: 运行 node _混淆工具.js 恢复 还原原始版本，检查修改是否有问题。

Q: 新增了HTML文件怎么办？
A: 把新文件同时放到根目录和 _原始未混淆版 文件夹，
   然后修改 _混淆工具.js 中的 TARGET_FILES 数组，添加新文件名。

Q: 防小白功能影响正常使用？
A: 防小白功能只禁用右键和快捷键，不影响页面正常点击和交互。
   如果需要临时禁用，可以在浏览器设置中禁用JavaScript。

========================================
七、维护建议
========================================

  1. 每次修改前，先确认 _原始未混淆版 是最新版本
  2. 修改后先在本地浏览器打开测试，确认无误再混淆推送
  3. 定期备份 _原始未混淆版 文件夹（可以复制到其他位置）
  4. 不要删除 _混淆工具.js 和 _原始未混淆版 文件夹
  5. git提交时，_原始未混淆版 和 _混淆工具.js 也会一起提交，方便以后恢复
