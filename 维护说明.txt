========================================
二、修改网站的正确流程（4步）
========================================

第1步：备份当前版本（每次改前必做）
  双击 备份当前版本.bat
  （自动镜像到 E:\全面备份\zhaolezi备份，
    并在 zhaolezi版本记录.txt 中记录快照）

第2步：修改原始文件
  打开 _原始未混淆版 文件夹
  修改需要改动的 HTML 文件（用记事本、VS Code等均可）
  保存文件
  ※ 图片放入 images/，音频放入 audio/，引用写相对路径
    （如 src="images/xxx.jpg"、src="audio/xxx.mp3"）

第3步：运行混淆脚本
  在 zhaolezi 文件夹中打开命令行（PowerShell或CMD）
  运行命令：
      node _混淆工具.js
  等待提示"完成：混淆 32，复制/写入 2，跳过/失败 0"

第4步：提交并推送
  运行命令：
      git add .
      git commit -m "修改说明"
      git push origin main
  等待1-2分钟，GitHub Pages自动更新，刷新网页即可看到效果

========================================
四、防小白保护与公共文件说明
========================================

1. common.js（自动生成）
   - 防小白保护：禁用右键菜单、F12、Ctrl+U 等查看源码手段
   - Service Worker 注册：离线缓存支持
   - 本文件由 _混淆工具.js 每次混淆时自动刷新，无需手动修改
   - 想调整保护内容，直接修改 _混淆工具.js 中的 ANTI_CHEAT_CODE

2. common.css（手动维护）
   - 多设备适配改进 v1.0（刘海屏/触摸优化/深色模式）
   - 游戏页面触摸优化（44px 触控目标）
   - 修改此文件即全站生效，无需改动各页面

3. service-worker.js（手动维护）
   - 缓存版本 zhaolezi-v2
   - 导航请求（页面）：网络优先，保证新版本及时生效
   - 静态资源（CSS/JS/图片/音频）：缓存优先，加快加载
   - 升级缓存策略后，把 CACHE_NAME 版本号 +1 即可强制刷新

========================================
五、备份与版本管理（重要）
========================================

1. 本地备份（防丢失）
   双击 备份当前版本.bat
   → 镜像到 E:\全面备份\zhaolezi备份（含 _原始未混淆版）
   → 版本记录写入 E:\全面备份\zhaolezi备份\zhaolezi版本记录.txt
   → 每次重大改动后，在版本记录末尾追加一条 --- Vn·日期·主题 ---

2. 源码不公开（防抄袭）
   _原始未混淆版/ 已被 .gitignore 忽略，不会上传 GitHub
   线上只发布混淆后的根目录文件
   保障：本地备份 + 版本记录（回滚 = 从备份复制对应文件回源）

3. 回滚方法
   从 E:\全面备份\zhaolezi备份 中找到要回滚的版本，
   把对应文件复制回 _原始未混淆版 或根目录即可。

========================================
六、常见问题
========================================

Q: 为什么不能直接修改根目录的HTML文件？
A: 根目录的HTML文件已经被混淆，代码是Base64编码的，直接修改会导致代码损坏。
   必须修改 _原始未混淆版 中的文件，然后重新混淆。

Q: 修改后网站没有变化？
A: 检查是否完成了4步：备份 → 修改原始文件 → 运行混淆脚本 → git push。
   另外GitHub Pages更新需要1-2分钟，可加 ?v=随机数 强制刷新缓存。
   （新版 service-worker 已改为导航网络优先，正常无需强刷）

Q: 混淆后网站功能异常？
A: 先确认 _原始未混淆版 修改无误，重新运行 node _混淆工具.js 即可覆盖。
   如问题依旧，从备份恢复该页面到 _原始未混淆版，再重新混淆。

Q: 新增了HTML文件怎么办？
A: 把新文件放入 _原始未混淆版 文件夹，然后运行 node _混淆工具.js。
   （脚本自动枚举目录内全部 .html，无需修改任何数组）

Q: 防小白功能影响正常使用？
A: 防小白功能只禁用右键和快捷键，不影响页面正常点击和交互。
