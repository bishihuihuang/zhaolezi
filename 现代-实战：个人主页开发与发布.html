一、项目目标

做一个"我的个人主页"：包含头像区、自我介绍、技能列表、一个按钮（点击弹窗），然后发布到 GitHub Pages，让全世界看到。本项目把 G1-G5 全部串起来，做完你就是一个能独立开发并上线网页的人。

二、第 1 步：搭骨架（HTML）

新建文件夹 my-homepage，里面建 index.html：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的个人主页</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="card">
    <img class="avatar" src="avatar.png" alt="我的头像">
    <h1>你好，我是小明</h1>
    <p class="intro">一个正在学习 Web 开发的新人。</p>
    <ul class="skills">
      <li>HTML</li><li>CSS</li><li>JavaScript</li>
    </ul>
    <button id="helloBtn">打个招呼</button>
  </div>
  <script src="script.js"></script>
</body>
</html>
💡 头像哪来？ 先随便放一张自己的照片/Emoji 图，命名 avatar.png 放同目录；后面想换随时换。

三、第 2 步：上妆（CSS）

同目录新建 style.css（G3 学的全用上）：

* { box-sizing: border-box; }
body {
  margin: 0; min-height: 100vh; display: flex;
  align-items: center; justify-content: center;
  background: linear-gradient(135deg, #667eea, #764ba2);
  font-family: "Microsoft YaHei", sans-serif;
}
.card {
  background: #fff; border-radius: 20px; padding: 32px 40px;
  text-align: center; box-shadow: 0 20px 60px rgba(0,0,0,.3);
  max-width: 360px; width: 90%;
}
.avatar { width: 96px; height: 96px; border-radius: 50%; object-fit: cover; }
.skills { list-style: none; display: flex; gap: 10px; justify-content: center; padding: 0; }
.skills li { background: #667eea; color: #fff; padding: 4px 12px; border-radius: 20px; font-size: 13px; }
#helloBtn {
  margin-top: 8px; border: none; cursor: pointer;
  background: linear-gradient(135deg, #11998e, #38ef7d);
  color: #fff; font-size: 15px; padding: 10px 22px; border-radius: 12px;
  transition: transform .2s;
}
#helloBtn:hover { transform: translateY(-2px); }

四、第 3 步：加肌肉（JS）

同目录新建 script.js：

const btn = document.getElementById('helloBtn');
btn.addEventListener('click', function () {
  alert('你好呀，欢迎来到我的主页！');
  console.log('按钮被点击了');
});

五、第 4 步：本地调试

  1. 双击 index.html 用浏览器打开，检查：头像显示、技能标签排成一行、按钮点击弹窗。
  2. 出问题就按 F12：图片不显示 → Network 看 404；按钮没反应 → Console 看报错。
  3. 满意后，用 F12 的设备模拟看手机上的效果。

六、第 5 步：发布上线

把项目变成 GitHub 仓库并开 Pages（F5 全流程）——只不过这次用你自己的 GitHub 账号，仓库名建议 my-homepage：

GitHub 新建 Public 空仓库 my-homepage（不勾 README 等）。
在项目文件夹打开命令行：git init → git add . → git commit -m "我的第一个网页"。
绑远程并推送：git remote add origin https://github.com/你的用户名/my-homepage.git → git push -u origin main。
仓库 Settings → Pages → Deploy from a branch → main / (root) → Save。
等 1-2 分钟，访问 https://你的用户名.github.io/my-homepage/ 🎉

七、升级练习

  • 加一个"自我介绍"段落，用 CSS 渐变卡片。
  • 加一个点击次数统计（G4 的计数器改造）。
  • 加第二页 about.html 并用 <a> 互相跳转。
  • 让技能标签 hover 变亮（transition）。

本课小结

  • 三件套合一：HTML 骨架 + CSS 样式 + JS 交互 = 个人主页。
  • 调试靠 F12：样式/报错/404 各找各的盘。
  • 发布 = init → add → commit → push → 开 Pages，和 F5 完全一样。
