一、设置：手机的总控制台

手机里所有功能的总开关都在设置 App（齿轮图标 ⚙）。怎么进去：

  1. 在桌面找到设置（齿轮图标）点开。
  2. 里面是一行行功能分类：WiFi、蓝牙、显示、声音、电池、存储、应用……
  3. 顶部有搜索框，输入"字体""亮度"等关键词，直接跳到对应设置——找不到时就搜一搜。
💡 快捷路径 顶部下滑两下出现的快捷开关面板，也能直接进 WiFi、蓝牙、亮度等常用设置，不用每次都翻设置菜单。

二、连接 WiFi 与移动数据

上网有两种方式：连家里的WiFi（无线网络，免费且稳定）和用手机卡的移动数据（流量，会消耗话费套餐）。

连接 WiFi 四步

  1. 打开设置 → WiFi（或顶部下滑点 WiFi 开关）。
  2. WiFi 开关打开后，下方列出附近所有网络名称。
  3. 点你家路由器的名字（一般问家里人叫什么），输入密码（在路由器底部标签或办宽带时的小卡片上）。
  4. 显示"已连接"就成功了。密码输错会提示，重新输入即可。
情况怎么上网
在家/店里有 WiFi连 WiFi，省流量
在外没有 WiFi用移动数据（注意别用超流量）
在陌生地方要联网可以问店家要 WiFi 密码；不要乱连不设密码的陌生 WiFi（J3 课提醒）
⚠️ 流量用超很贵 看视频、刷短视频最费流量。在家一定连 WiFi；用流量时注意手机顶部有没有"4G/5G"标识，感觉不对就关掉移动数据开关。

三、声音、亮度与长辈模式

设置项位置用途
音量设置→声音；或机身侧面音量键调铃声、媒体音量（听歌看视频）
亮度设置→显示；或顶部下滑拖滑块屏幕太暗伤眼、太亮费电
字体大小设置→显示→字体大小字调大，看消息更省眼
长辈/简易模式设置→长辈模式（各品牌名称不同）一键把图标、字体、音量整体调大，界面简化，强烈推荐开启
勿扰模式设置→声音→勿扰睡觉时段不响铃不打扰
💡 长辈模式开启方法 大多数手机在「设置 → 长辈模式 / 简易模式 / 极简模式」里开启，有的手机直接搜索"长辈"两个字就能找到。开一次，字体图标全变大，很多老人用着用着就离不开了。

四、存储清理：手机瘦身

手机提示"存储空间不足"、越来越卡，多半是照片、视频和微信聊天缓存占满了。怎么查和清：

  1. 打开设置 → 存储（有的手机叫"存储空间"），能看到哪类东西占最多。
  2. 照片视频：清理没用的截图、重复照片（H4 课的相册整理）；开了云备份的可放心删本地副本。
  3. 微信缓存：微信 → 我 → 设置 → 通用 → 存储空间 → 缓存"清理"（聊天记录不会丢）。
  4. 系统自带的"手机管家/清理大师"App 一键清理垃圾，省心。
能放心清别乱动
缓存、临时文件、安装包聊天记录（先备份再考虑）
没用的照片、旧视频银行、支付 App 里的任何文件
不用的 App（先卸载再清）系统自带的"系统应用"（卸载会出问题）
⚠️ 清理三不碰 不碰系统文件、不碰银行/支付类 App 数据、不碰你不认识的文件。只清"缓存"和明知道没用的东西，就不会出错。

五、电池省电与充电常识

  • 电量焦虑的真相：正常用一天到两天没问题；掉电快先查是不是后台 App 太多（设置→电池 看谁最耗电）。
  • 省电设置：降低屏幕亮度、关掉用不到的蓝牙/定位、开"省电模式"。
  • 充电常识：随用随充，不用非等电量耗尽；用原装充电器最安全；睡觉充到 100% 没大问题，不必焦虑。
  • 发热正常：边充边玩游戏、充电时手机发热是正常现象，过热会自己降速保护；别把手机压在枕头下充电。
🧠 一句话 手机电池是消耗品，正常用、别过充过放，用两三年换一块电池很平常，不用当"心头大患"。

本页小结

  • 设置是手机总控制台，找不到就用顶部搜索框搜。
  • WiFi 上网免费稳定，在家优先连 WiFi；流量注意别超。
  • 给老人强烈建议开长辈模式；清理存储只清缓存和确定没用的，不碰系统文件。
🤔 课后练习 打开设置，把字体调大一号，并找到"长辈模式"试着看一眼；再查一下手机存储，看看是哪一类东西占的空间最大。
