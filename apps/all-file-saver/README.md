# 全能文件保存 · 线上版

> 一个可在浏览器直接使用的「文本 + 文件」分类管理工具：标签分类、时间追溯、状态标记、置顶、回收站、导出导入、11 套主题。
> **线上版为纯前端实现，数据只存你的浏览器本地（localStorage + IndexedDB），不上传任何服务器。**

## 在线使用

打开 GitHub Pages 地址即可直接使用（建议使用 Chrome / Edge）。

首次使用会看到空列表，左侧输入内容或选择文件后点「保存条目」即可开始记录。

## 功能一览

| 功能 | 说明 |
|---|---|
| 文本/文件保存 | 文本多行记录；文件保存到浏览器 IndexedDB（单文件 ≤ 30MB） |
| 状态标记 | 重要 / 次要 / 待办 三档，可一键切换 |
| 置顶 | 重要条目置顶显示 |
| 标签分类 | 每条最多 5 个标签，可筛选 |
| 搜索 | 标题 / 正文 / 标签 / 文件名 / 时间全文检索 |
| 回收站 | 删除先入回收站，可恢复或彻底清除 |
| 导出 / 导入 | TXT / Markdown / JSON 三种格式；JSON 可与本地版互通 |
| 主题 | 11 套内置主题 + 自定义主题（背景 / 配色 / 圆角 / 模糊全可调） |
| 离线可用 | PWA 支持，安装后离线打开 |

## 数据与隐私

- 所有数据（条目 + 文件）**只保存在你自己的浏览器里**，刷新、关闭、重开都还在（同一浏览器同一域名下）。
- 清除浏览器站点数据 = 清除全部数据。**重要数据请定期「立即备份数据」导出 JSON 存档。**
- 换浏览器 / 换设备 / 清除缓存前，请先导出 JSON 备份，再到新环境导入。
- 本项目不接入任何后端、不上传任何数据、无账号体系。

## 本地开发 / 修改

```text
_原始未混淆版\           ← 源码（修改在这里改）
全能文件保存系统\         ← 混淆发布版（由工具生成，勿直接修改）
_obfuscate.js             ← 混淆工具（Node.js 脚本）
一键自动化发布.bat        ← 一键：拉取-混淆-提交-推送
```

修改流程：

1. 编辑 `_原始未混淆版\全能文件保存.html`
2. 双击 `一键自动化发布.bat`（自动混淆并推送到 GitHub Pages）
3. 等待 1-2 分钟，刷新线上页面验证

单独生成发布版（不推送）：`node _obfuscate.js`

## 技术说明

- 纯 HTML + CSS + JavaScript，无任何后端依赖
- 数据：条目存 localStorage，文件存 IndexedDB
- PWA：manifest.json + service-worker.js，支持离线与安装
- 混淆：base64 + 字符串逆序双层处理（见 _obfuscate.js）
