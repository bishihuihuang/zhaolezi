# 现代化·知识学习站（xiandaihua）

面向初学者的免费学习站：**计算机基础、电脑详细使用、网络与服务器、键盘快捷键、
如何使用 AI、Git 与 GitHub、Web 开发入门、手机与平板、微信与生活服务、
网络安全与防诈骗、办公与文档、网上购物与现代消费、数字生活进阶、旅游与出行**。
十四个学习模块 + 学习系统 + 关于本站，
共 127 个页面（`XD.TREE` 登记 125 个节点 + `index.html`/`1.html` 两个门户页），
含 19 个目录页、13 套结业测验、9 个互动工具、26 枚成就徽章。
纯 HTML/CSS/JS 手写，零框架零依赖，支持离线（PWA），GitHub Pages 直接部署。
内置 XP 等级、每日任务、首次导游与考后解析等游戏化引导系统。
视觉层为纯 CSS 玻璃拟态：光随鼠走、玻璃停靠栏、液态模块导航条、模块就地放大、
水滴分裂筛选、Ctrl+K 命令面板——全部无第三方库，`common.css` + `xd-features.js` 一处实现全站生效。

## 目录结构

## 命令

在**顶层**（`E:\上传网页\现代化`）执行：

```bash
cd 构建工具 && npm install   # 首次：装开发期依赖（jsdom，仅供冒烟测试用）
node 构建工具\_构建.js       # 静态体检 + sitemap/robots 生成 + SW 升版 + 同步上线网页（发布前必须 exit 0）
node 构建工具\serve.js       # 本地预览 http://127.0.0.1:8866（冒烟测试需要它在跑）
node 构建工具\smoke.js       # 动态冒烟：127 页逐页真实执行脚本，抓运行时错误
npm run build                # 等价于 node 构建工具\_构建.js（serve / smoke 同理）
```

`构建工具/_构建.js` 与 `构建工具/smoke.js` 是两道互补的闸门，**发布前都要过**（不要同时跑）：

| 检查 | 抓什么 |
| --- | --- |
| `node 构建工具\_构建.js` | 语法、内链失效、公共资源缺失、树-文件一致性、门户页存在性 |
| `node 构建工具\smoke.js` | 运行时错误、`pageInit` 是否渲染面包屑/前后页、`XD.*` 层是否可用、前后页是否链到合法页面 |

## 维护规范

1. **明码维护**：本站是教学站，源码即线上代码，直接改 `原版源文件/` 里的 HTML 即可
   （无混淆、无压缩、无打包步骤）。
2. **改源码，别改发布根**：`上线网页/` 每次构建都会被 `原版源文件/` 整份覆盖，
   手改发布根等于白改。
3. **页面登记**：页面文件统一以 `节点 id + .html` 命名（如 `E2.html`），平铺在
   `原版源文件/` 内。模块树在 `原版源文件/xd-features.js` 的 `XD.TREE` 定义
   （单一来源，构建与站内搜索/面包屑/前后页/进度都由此生成）——新增页面只需加节点，
   不要改 `XD.PAGES`（那是派生的）。
4. **文件命名是合同**：`XD.TREE` 里 `id` 一旦发布不可改名——目录页用
   `data-kind="dir"` + `XD.renderDir('dir', '<节点id>')` 渲染子模块卡片。
5. **不要手改** `service-worker.js` 的缓存版本与 `ASSETS`（构建自动生成）；
   `sitemap.xml`/`robots.txt` 同理由构建生成（都生成在 `原版源文件/` 内）。
6. **换仓库名**：改 `构建工具/_构建.js` 顶部 `REPO` 常量，并把顶层
   「一键发布到GitHub.bat」里的 `REPO` 一起改掉，重跑构建即可更新全部域名引用
   （sitemap/robots 的 SITE_BASE 与 SW 的缓存域名保持一致）。
7. 页面配色一律使用 CSS 变量（见 common.css `:root`），保证 10 套主题下可读；
   风格类名（`.callout`/`.xd-table`/`.code-block`/`.step-list` 等）优先复用。
8. localStorage 键统一 `xd_` 前缀；跨页数据只由拥有方写入，消费方只读+订阅事件。
9. 本站**不禁右键、不禁 F12**——模块 G 第 5 课要教开发者工具，不能自相矛盾。
10. 测验 id 固定 `A/B/C/E/F/G/H/I/J/K/L/M/N` 十三个（键盘模块 D 用练习器考核，无测验页）；
    成就解锁参考 `xd-features.js` 的 `XD.ACHIEVEMENTS`。
11. **内容页骨架三件套缺一不可**（`构建工具/_构建.js` + `构建工具/smoke.js` 都会查）：
    `body data-page="X.html"`、面包屑容器、`<nav id="xdPrevNext">` 前后页容器。
    目录页（`data-kind="dir"`）不需要前后页容器。新增页面照抄已有同型页面的骨架。
12. **改动后跑两道闸门**：`node 构建工具\_构建.js`（静态）+ `node 构建工具\smoke.js`（动态，
    需先在另一终端跑 `node 构建工具\serve.js`）。两关**不要并发跑**：构建脚本会对每页
    内联脚本各起一个 `node --check`，和冒烟的 jsdom 同时抢 CPU 会让 node 直接崩溃。
    曾靠这两道查出过：门户页漏出 sitemap/SW 缓存、三个测验页缺前后页容器、
    Canvas 无降级保护。

## 发布

入口是顶层「说明.txt」（两条日常操作 + 上传步骤），详细版见 `发布指南.md`
（也可看站内 C5「网站托管与 GitHub Pages」、F5「上传全流程」，内容一致）。

- **`上线网页/` 就是 GitHub 仓库**（`.git` 在里面）。首次在 GitHub 网页新建空仓库
  `xiandaihua` 后，双击顶层「一键发布到GitHub.bat」即可——脚本会自动配好 remote、
  跑体检、同步站点、提交、推送。平时更新也只需双击这一个脚本。
- **GitHub Pages 的源目录要选 `/(root)`**（仓库设置 → Pages → Build and deployment →
  Branch `main` → Folder `/(root)`）。站点文件就在仓库根，选成别的子文件夹线上会是 404。
  这样线上地址是 `https://bishihuihuang.github.io/xiandaihua/`，站内链接、sitemap、
  Service Worker 全部不受影响。
- **别手动 `git push`**：`原版源文件/.git`（源码仓库，本地留档，保留全部提交历史）与 `上线网页/.git`
  （发布仓库）都指向同一个 GitHub 仓库，手动推会互相冲突（`rejected ... fetch first`）。
  上传一律走脚本；源码仓库的 `.git` 只作本地历史留档。
- 本地拆成三个文件夹加一个脚本和一个说明文件，只是为了让「要改的源码」「要发的成品」「开发工具」「一键脚本」各归各位；
  站点内容本身一个字节没多。
