一、服务器的本质

服务器就是一台电脑——只是"专干服务活"：常年开机、监听端口、响应请求（C1 的客户端-服务器模型里的"服务方"）。它和我们家用的电脑区别在于：

  • 不关屏 / 不关机：7×24 小时待命，坏一台要能顶上。
  • 性能与可靠优先：多核 CPU、大内存、ECC 内存（纠错）、磁盘阵列 RAID（坏一块盘数据不丢）。
  • 没有多余花哨：一般不带显示器键盘，装好后远程管理。
💡 服务器并非"高档神秘物" 从原理上，你淘汰的旧电脑插上网线、装个 Web 软件，就能当一台"家用服务器"给局域网提供网页/文件共享——这就是很多极客的"NAS/私有云"。差别只在稳定、安全、带宽这些"搬进机房"后才有的保障。

二、机房：服务器的家

大网站把成千上万台服务器放进数据中心（机房）：

  • 供电：双路市电 + UPS 电池 + 柴油发电机，断电不停机。
  • 散热：冷通道/热通道设计、精密空调；一度电给计算、还得小半电散热。
  • 网络：多条冗余光纤接入，带宽按 Gbps/Tbps 计。
  • 安防：门禁、监控、消防（气体灭火），专人 24 小时值守。

三、云服务器：不用买也能租

普通人不买机房，而是租云服务器：阿里云、腾讯云、华为云、AWS、Azure 等把一台物理机用"虚拟化"切成很多台虚拟机租给你，像租公寓一样按需付费。

概念类比你要做的事
云服务器 ECS/EC2租了一台"裸电脑"（含系统）自己装环境、配置、交月租
对象存储 OSS租了一个超大网盘/仓库专门存图片视频等静态文件
托管/PaaS拎包入住只传代码，平台管运行（如 GitHub Pages）
💡 学生/新手白嫖攻略 各大云厂商对学生有免费试用/低价云主机；而最便宜的"托管"方案，是 C5 要讲的 GitHub Pages——静态网站完全免费，本站就打算用它发布。

四、Web 服务器软件

服务器要"会答网页请求"，得跑一个 Web 服务器软件：

软件特点在哪见
Nginx轻快、高并发，如今事实标准绝大多数网站/REST API 前端
Apache老牌稳定，配置直白老站、传统主机商
IISWindows 自带企业内部 Windows 服务

它干的活：监听 80/443 端口 → 收到请求 → 找到对应文件/执行程序 → 返回响应。F 模块你上传到 GitHub Pages 之后，背后就是 GitHub 的 Nginx/对象存储替你干这些。

五、静态 vs 动态网站

类型特点代表
静态网站纯 HTML/CSS/JS 文件，谁来访问都给同一份；简单、快、防火、便宜个人主页、文档站、本站
动态网站程序（PHP/Python/Java 等）按请求现算现生成；能登录、评论、购物车电商、论坛、SaaS

动态站=静态站 + 后端程序 + 数据库（如 MySQL/PostgreSQL）。本站是纯静态的（G 模块会学怎么写），这也是它免费、离线可用的原因。

六、服务器系统与运维常识

  • 服务器操作系统 90%+ 是 Linux（Ubuntu Server / Debian / CentOS 系），免费且稳定。
  • 管理员通过 SSH（端口 22）远程登录配置，像"远程遥控一台没有屏幕的电脑"。
  • 运维日常：更新补丁、看日志、监控告警、备份、扩容。云服务器崩了数据丢了？——还是要自己有备份思维（B6 同理）。
