一、GitHub 是什么

GitHub 是全世界最大的代码托管平台：把你的 Git 仓库放到云端，别人能看到/下载/协作你的代码。它也是全球开源协作的中心，你日后学编程十有八九要在上面泡着。本模块把本站发布到 GitHub Pages 就是靠它。

二、注册账号

打开 github.com，点右上角 "Sign up"，用邮箱注册并验证。
设置用户名（将来你的网站地址就是 用户名.github.io，本站是 bishihuihuang）和密码。
注册后去邮箱点确认邮件，完成。
⚠️ 账号安全 务必开启二步验证（Settings → Password and authentication → Two-factor authentication）。GitHub 账号泄露 = 你所有代码被改，别大意。

三、创建仓库

点右上角 + → "New repository"。
填仓库名（如 xiandaihua）、选 Public/Private（公开=别人能看，私密=只有你）。
可以勾选 "Add a README file"（推荐），其余保持默认，点 "Create repository"。

建好后页面会给三组命令（远程还没内容时）或克隆命令（带 README 时）——F5 会带你走完整流程。

四、HTTPS 还是 SSH

方式原理优点缺点
HTTPS推送时输用户名 + 访问令牌（Personal Access Token）配置简单，一个令牌到处用令牌有有效期，到期要换
SSH本机生成密钥对，公钥贴到 GitHub一次配置长期免密、更安全首次生成/配置稍麻烦
# HTTPS 推送示例（F5 主要用它）
git push
# 提示登录：用户名 + 令牌（不是密码！）
💡 令牌去哪拿 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，勾选 repo 权限，生成后立即复制保存（只显示一次）。

五、README：仓库的门面

README.md 是仓库主页显示的介绍文件（Markdown 格式）。写清楚：这是什么项目、怎么用、目录结构。本站首页 README 就会写"现代化·知识学习站"的介绍和页数。

六、克隆与浏览开源项目

看到喜欢的开源项目，点 "Code" 按钮复制地址，然后：

git clone https://github.com/用户名/仓库名.git
cd 仓库名

克隆下来的就是一份完整仓库，可自由学习、修改、提建议（开源项目的核心玩法）。注意：克隆 ≠ 拥有版权，商用/转载看清仓库的 License。

本课小结

  • GitHub = 云端 Git 仓库 + 全球开源协作平台。
  • 建仓在 "+" → New repository；连接方式 HTTPS（令牌）或 SSH（密钥）。
  • README 是门面；clone 可把开源项目搬到本地学习。
