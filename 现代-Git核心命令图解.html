一、三区流程图

工作区
(你编辑的文件)→ git add → 暂存区
(购物车)→ git commit → 版本库
(快照库)→ git push → 远程仓库
(GitHub)

下载别人/同步回来则走反向：git pull（远程 → 本地）。一句话记忆：改 → add → commit → push。

二、git init：开仓库

在项目文件夹里执行一次，让 Git 开始管理这个目录（会生成隐藏的 .git 文件夹）：

cd 你的项目文件夹
git init
# 输出：Initialized empty Git repository in ...

三、git status：看状态

任何时候迷路都先敲它——它告诉你"哪些文件改了、哪些还没暂存、哪些还没提交"：

git status
# 红色 = 工作区有改动未暂存
# 绿色 = 已暂存待提交
# "nothing to commit" = 一切干净

四、git add：进暂存区

git add 文件名        # 暂存指定文件
git add .            # 暂存当前目录所有改动（最常用）
git add *.html       # 暂存所有 html 文件
💡 为什么有这一步 防止把不想提交的东西（如密钥、临时文件）顺手存进快照。谨慎提交是好习惯。

五、git commit：存快照

把暂存区的内容正式归档成一张快照，必须写说明（让别人和未来的你明白这版干了什么）：

git commit -m "添加首页导航栏"
# 输出：1 file changed, 42 insertions(+)

养成习惯：一次提交只做一件事，说明用动词开头、简短清楚，例如本站的提交就是 M6: 模块D 键盘与快捷键…。

六、git log：看历史

git log              # 完整历史（按时间倒序）
git log --oneline    # 精简版：一行一个提交
git log --oneline -5 # 只看最近 5 条

每条记录包含：提交编号（一长串哈希）、作者、日期、说明。想回到旧版本用 git checkout 编号 -- 文件 或 git reset（演练场 F6 会练）。

七、push 与 pull：连接远程

先要有远程仓库（F4 教你建）。关联后：

git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main    # 第一次推送，-u 记住目标分支
git push                   # 之后只需这样
git pull                   # 拉取远程最新改动

推送需要身份验证（HTTPS 用账号+令牌，或 SSH 密钥）——F4/F5 详讲。本站发布就靠 git push 到 GitHub Pages 仓库。

八、速查表

命令作用
git init把当前目录变成仓库
git status查看改动状态
git add .暂存全部改动
git commit -m "说明"提交快照
git log --oneline查看提交历史
git diff查看具体改了什么
git push本地提交推送到远程
git pull远程更新拉回本地
git clone 地址把远程仓库整个复制到本地
💡 高频组合拳 日常改代码的三连：git add . → git commit -m "..." → git push。先练熟这三条，其他命令随用随查。

本课小结

  • 三区：工作区 → add → 暂存区 → commit → 版本库 → push → 远程。
  • status 是导航，log 是历史；commit 说明要清楚，一次只做一件事。
  • 高频组合拳 add → commit → push，先练熟它。
