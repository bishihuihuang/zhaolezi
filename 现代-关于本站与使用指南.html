🧭 关于本站与使用指南

它是什么、怎么用、以及如何部署成你自己的网站

一、本站是什么

「现代化·知识学习站」是一份全中文、面向零基础的综合性学习资料：从认识电脑硬件、学会日常操作，到理解网络与服务器、练出盲打和快捷键肌肉记忆，再到上手 AI、Git 和网页开发——按 模块 → 子模块 的目录树组织，点进模块就能看到细分子模块，目录还可以再套目录（最深 10 层），每页都有面包屑定位。

💡 本站的技术特点 纯静态页面 + PWA：没有后台数据库、不需要注册登录、不依赖任何外链资源。学完一页后你的进度、成绩、错题都保存在你自己浏览器的本地存储里，隐私安全。

二、建议的学习路径

  1. 模块 A 计算机基础：先知道电脑的硬件和软件是怎么回事。
  2. 模块 B 电脑详细使用：Windows 操作、文件管理、软件安装、系统设置。
  3. 模块 C 网络与服务器：上网原理、IP/域名、服务器与建站基础。
  4. 模块 D 键盘与快捷键：指法 + 快捷键速查 + 练习器 + 打字测试，练出肌肉记忆。
  5. 模块 E 如何使用 AI：认识大模型、学会写提示词、用对工具。
  6. 模块 F Git 与 GitHub：版本控制 + 把网页发布到 GitHub Pages。
  7. 模块 G 怎么开发网页：HTML/CSS/JS 三件套 + F12 调试 + 实战发布。
  8. 模块 H 手机与平板：触屏手势、App 安装、拍照、设置，把智能手机用明白。
  9. 模块 I 微信与生活服务：聊天、支付、挂号出行，把生活服务搬进手机。
  10. 模块 J 网络安全与防诈骗：密码与骗术拆解、AI 新骗局、被骗后止损报警。
  11. 模块 K 办公与文档：Word/Excel/PPT、WPS 云文档与电子邮件。
  12. 模块 L 网上购物与现代消费：网购入门、下单支付、物流收货、退换货售后与直播团购。
  13. 模块 M 数字生活进阶：短视频、智能电视、智能家居、数字政务、线上就医与备份换机。
  14. 模块 N 旅游与出行：出行规划、火车高铁、飞机、酒店住宿、景区预约与旅途防坑。

每个模块末尾都有结业测验（60 分通过）；最后到 学习仪表盘 看进度，到 成就墙 收集徽章，错题会集中在 错题本 里随时复习。学课途中遇到看不懂的词，到 术语词典 查它的大白话解释；14 个模块全部学完，再到 毕业证书 领取你的毕业证明并打印出来。

三、怎么记录进度

  • 打开任意一课，该页自动标记为"已读"（右下角会弹提示）。
  • 测验做完自动保存最好成绩，答错的题进错题本。
  • 练习器（快捷键、打字、鼠标、Git 演练场、诈骗识别）保存最佳记录，打字成绩可解锁成就徽章。
  • 不知道该学哪一课？到 生活场景速查，按眼下的生活问题直接找到对应教程。
  • 连续 3 天学习、读完 20 个页面、完成整个模块，都有对应徽章。

想清空重来？清除浏览器里本站的站点数据即可（开发者工具 → Application → Storage → Local Storage → 本站域 → Clear）。

四、如何把本站部署到你的 GitHub

本站没有任何服务器依赖，可以整个文件夹免费托管在 GitHub Pages 上。详细步骤见 F5 上传网页到 GitHub Pages 全流程，这里给个速览：

在 GitHub 新建一个仓库（Public，不勾选 README/.gitignore/license），例如叫 xiandaihua。
本地把整个站点文件夹变成 Git 仓库并提交（本项目的 _构建.js 会自动生成站点地图与缓存清单）。
把远程地址指到你的仓库并推送：git remote add origin https://github.com/你的用户名/xiandaihua.git，然后 git push -u origin main。
到仓库 Settings → Pages → Build and deployment → Source 选 Deploy from a branch，分支选 main，目录选 /(root)，保存。
等一两分钟，访问 https://你的用户名.github.io/xiandaihua/ 即可看到你的站点。
⚠️ 发布小贴士 推送到公开仓库意味着这些文件任何人可见，上传前确认里面没有隐私信息（比如密钥、token）。Git 的用户名/邮箱推荐使用 GitHub 的 noreply 匿名邮箱，保护真实邮箱不被公开抓取。
