一、桌面与开始菜单

开机后的大画面是桌面，左下角是开始菜单（Win 键触手可及）：

  • 按 Win 或 Ctrl+Esc 打开开始菜单，可搜索任何程序/设置（按笔记本品牌 Fn 键位不同，这里指键盘上带 Win 图标的键）。
  • 开始菜单的搜索框是最快的"启动器"：输入前几个字母回车就能打开程序。
  • 桌面图标：双击打开；右键可排序、新建文件夹。删错的图标不用慌，一般只是快捷方式。
💡 快捷方式 vs 真身 桌面上的图标大多带个小箭头，是"快捷方式"（指向程序的链接）。删掉快捷方式不影响程序本身；但把"D盘 本人照片 不备份"这类真文件删了，就真的没了——分清这两者是文件安全的第一课。

二、窗口：移动、缩放与分屏

操作做法
移动窗口按住标题栏拖动；或 Win+方向键左右分半屏
最大化 / 还原双击标题栏，或拖动窗口到屏幕顶端
四分之一分屏Win + 方向键后接着按上下键微调
快速切换窗口Alt+Tab 循环切换（按住 Alt 不放）
最小化除当前外全部按 Win+Home；点右上角"显示桌面"小条

分屏是效率神器：一边写文档一边查资料，把两个窗口各拖向屏幕左右两侧即可各占一半。

三、虚拟桌面：多开一套屏幕

按 Win+Tab 进入任务视图，右上角"新建桌面"可以开第二、第三个"独立桌面"——一个桌面放工作，一个放娱乐，互不干扰。切换：Ctrl+Win+←/→。

💡 什么时候用 汇报前开一个"干净桌面"；游戏开黑不想让家人看到作业进度条？虚拟桌面一键切走，比最小化优雅得多。

四、截图全家桶

  • Print Screen（PrtSc）：截全屏到剪贴板，去画图/Ctrl+V 粘贴。
  • Win+Shift+S：截图工具（区域截图，可框选任意矩形，是现代主流）——截完直接 Ctrl+V 粘贴即可，无需保存。
  • Alt+PrtSc：只截当前窗口。
  • Win+G：游戏栏里的录屏（非截图场景）。

五、任务栏与通知中心

  • 任务栏：底部一栏，把常用程序"固定"到这里（右键→固定到任务栏），以后一键打开。
  • 通知中心：右下角时间旁的图标区，藏着一堆后台程序（如 QQ、微信）。右键图标可退出，避免开机自启一堆。
  • 托盘"✅"角标：存储"隐藏的图标"，点开可以复位到任务栏。
⚠️ 开机自启是"卡顿元凶" 右键任务栏 → 任务管理器 → 启动应用：把不用的全部禁用。十个开机自启 = 开机慢半分钟，内存还悄悄被吃。

六、右键菜单的奥妙

右键堪称 Windows 的"万能菜单"。常用项：新建（文件夹/文本）、复制/剪切/粘贴、压缩到 ZIP、属性（看大小/位置）、发送到（桌面快捷方式）。Win11 下右键 → 显示更多选项 可展开全部。

🤔 课后思考 想在桌面上建一个"work"文件夹并把今天下载的照片放进去——用右键 + 拖拽完成它，全程试用快捷键加分：Win+E 打开文件管理器（B2 会细讲）。
