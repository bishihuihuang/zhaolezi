一、手机文件都藏在哪

手机里的照片、下载的文档、截图，各有各的"抽屉"：

想看什么去哪找
拍的照片、截图、视频手机自带的"相册/图库"App（H4 讲过的相册，就它）
下载的文件（PDF、Word 等）安卓"文件管理"App → 内部存储 → Download（下载）；苹果"文件"App → 下载
别人发我的文档微信里收的，一般要先"用其他应用打开/保存"才会进文件管理
通话录音、录音笔记手机"录音机"或"备忘录"App 里
💡 找不到？用搜索 桌面下拉出搜索框，输文件名大致名字（如"合同"），基本都能翻出来（复习 H1 触屏手势 的搜索手势）。

二、微信文件去哪找

收到的文件：微信聊天里点开文件 → 右上角"···"→"保存到手机/转发"；要长期留就另存一份。
微信缓存清理："我 → 设置 → 通用 → 存储空间"，能看"聊天记录+缓存"占了多少；清理缓存不影响聊天文字，但小心别清掉你没转存的视频图片（复习 H5 存储清理的提示）。
传到电脑：电脑登录微信 → 手机上"文件传输助手"发文件过去；或右键电脑微信聊天里的文件"另存为"。
重要文件双保险：合同、证件照这类，建议同时存一份到云（下节讲），别只躺在微信里——换手机或清缓存容易没。

三、照片云备份：免费额度怎么用

  • 手机自带云：小米云服务、华为云空间、苹果 iCloud 都送一定免费空间（一般 5GB 左右），照片多了一会就满。
  • 运营商/网盘：和手机同品牌的云原图和安全；第三方网盘（百度网盘、阿里云盘）免费额度较大，上传前看清"非会员限速、压缩照片"等条款。
  • 自动备份怎么开：相册设置里开"自动备份/云相册"→ 连 WiFi 时自动把照片传到云端。一开一劳永逸，手机丢了照片还在。
  • 备份≠万事大吉：云端也有倒闭/关停风险，真正重要的家庭老照片，每年手动拷一套到电脑或 U 盘（K4 WPS 云文档 的道理一样：本地+云端双保险）。
⚠️ 隐私照别传云 证件照、隐私照片别上云（云被人撞库泄露的新闻常有），放手机本地+加密相册即可。

四、换新手机：数据搬家

同品牌最快：小米"手机克隆"、华为"手机克隆"、苹果"快速开始"，新旧两机放一起，新机跟提示一步步走。
跨品牌："换机助手"类 App（如手机厂商自带），或先把资料备份到云/电脑再搬到新机。
微信聊天记录单独搬：微信内置"我 → 设置 → 通用 → 聊天记录迁移与备份 → 迁移到另一台设备"，新旧手机连同一 WiFi，扫码后自动传。
通讯录自动跟：登录同一账号（小米/华为/苹果），通讯录基本自动同步；别手动一个一个输。
搬到一半停网：换机最忌讳频繁断网，挪到客厅离路由器近的地方一次搬完。

五、老手机善后

先确认新机完整：照片、通讯录、微信、政务 App（M4 电子社保卡）都能打开、登录正常。
退出账号：微信、支付宝、银行 App、云相册，先退出登录（J1 有登出入口的方法）。
恢复出厂："设置 → 系统/通用 → 恢复出厂设置"，把照片、账号、聊天记录清干净（旧手机卖二手或送人前必须做）。
旧手机还没卖：留着当"备用机"也行，但同样做好退出+锁屏密码。

本课小结

  • 照片在相册、下载文件在文件管理；找不到就用桌面搜索。
  • 微信文件要"保存/另存"才跑得掉缓存清理；重要文件本地+云双保险。
  • 云备份开"自动备份"防手机丢失；隐私照别上云。
  • 换机：同品牌克隆 → 跨品牌云/电脑 → 微信单独迁移；老手机先退账号再恢复出厂。
