一、CSS 怎么"穿"到 HTML 上

三种方式：外部文件（推荐）、页内 <style>、内联 style 属性：

<!-- 外部：head 里引入，全站复用（本站的 common.css 就是） -->
<link rel="stylesheet" href="xd-common.css">

<!-- 页内：只给本页用 -->
<style> h1 { color: red; } </style>

<!-- 内联：只给一个元素用（优先级最高，慎用） -->
<p style="color: blue;">…</p>

二、选择器

CSS 规则 = 选择器 + 声明块：选谁、改什么。

/* 标签选择器：所有 p 段落 */
p { color: #333; }

/* 类选择器：class="card" 的元素（. 开头） */
.card { border-radius: 12px; }

/* id 选择器：# 开头，页面唯一 */
#logo { width: 60px; }

/* 后代选择器：.nav 里的 a 链接 */
.nav a { text-decoration: none; }
💡 类 vs id 一个元素可以有多个类（class="card card-blue"）用来组合样式；id 一页只能有一个。本站大量用类选择器。

三、颜色、字体与文字

.title {
  color: #667eea;              /* 文字颜色（十六进制） */
  background: linear-gradient(135deg, #667eea, #764ba2); /* 渐变背景 */
  font-size: 24px;             /* 字号 */
  font-weight: 800;            /* 字重：粗体 */
  text-align: center;          /* 居中 */
  line-height: 1.8;            /* 行距 */
  font-family: "Microsoft YaHei", sans-serif; /* 字体栈 */
}

四、盒模型

每个元素都是一只"盒子"：从外到内是 margin（外边距）→ border（边框）→ padding（内边距）→ 内容。

.card {
  width: 300px;
  padding: 16px;        /* 内容和边框之间的空间 */
  border: 2px solid #e8e8e8; /* 边框 */
  border-radius: 12px;  /* 圆角 */
  margin: 20px auto;    /* 外边距：上下 20，左右自动居中 */
  box-sizing: border-box; /* 重要：让 padding 计入宽度，不撑大盒子 */
}
⚠️ 最坑的一课 不给 box-sizing: border-box 时，width 300 + padding 16×2 + border 2×2 = 实际 336px，布局就"爆了"。建议全局都开：* { box-sizing: border-box; }

五、Flex 布局：排排站

把一堆元素水平/垂直排列，Flex 是最常用方案：

.row {
  display: flex;              /* 开启弹性布局 */
  justify-content: space-between; /* 主轴对齐：两端分布 */
  align-items: center;        /* 交叉轴：垂直居中 */
  gap: 12px;                  /* 元素间距 */
  flex-wrap: wrap;            /* 放不下自动换行 */
}

本站首页的模块卡片、导航、表格行几乎都靠 Flex 排布——按 F12 选一个 .card 看看它的样式。

六、CSS 变量：一套主题

把常用颜色存成变量，换主题只需改一处：

:root {
  --blue: #667eea;
  --line: #e8e8e8;
}
.card { border: 1px solid var(--line); color: var(--blue); }

本站的暗色/金色主题就是这么实现的（theme.js 换一套变量值，全站跟着变）。

七、实战：给按钮变好看

<button class="btn">点我</button>

.btn {
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: #fff;
  border: none;
  padding: 10px 20px;
  border-radius: 10px;
  cursor: pointer;
  transition: transform .2s;   /* 动画过渡 */
}
.btn:hover { transform: translateY(-2px); } /* 悬停上浮 */

做完在浏览器打开，把鼠标放上去——按钮会"浮起来"。这就是你写的第一个交互样式。

本课小结

  • 选择器：标签/类/ id/后代；规则 = 选谁 + 改什么。
  • 盒模型从外到内：margin → border → padding → 内容；记得 box-sizing。
  • Flex 排布局、CSS 变量管主题、hover + transition 做动效。
