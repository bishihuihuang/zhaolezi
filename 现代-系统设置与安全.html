一、设置中心：一切从这里开始

按 Win+I 打开设置：系统的"控制台"。常用入口速记：

想干什么去哪找
换壁纸/主题/屏保设置 → 个性化
看机器配置设置 → 系统 → 关于
管理开机自启设置 → 应用 → 启动（或任务管理器）
连接蓝牙/打印机设置 → 蓝牙和其他设备
改网络/DNS设置 → 网络和 Internet
电源与睡眠设置 → 系统 → 电源

二、Windows 更新与 Defender

  • Windows 更新（设置 → Windows 更新)：补丁修复漏洞，别长期禁用。"关机并更新/更新并重启"要顺手做。
  • Windows Defender：系统自带的实时防护，已够用。设置 → 隐私和安全 → Windows 安全中心 → 病毒和威胁防护，开"实时保护"。
  • 疑点文件可右键 → 用 Defender 扫描；真中了"勒索/木马"，马上断网 + 全盘扫描（B6 有处置流程）。
💡 别双杀毒 同时装 Defender + 某管家 + 某杀软，三个杀软互相"斗法"，卡到你怀疑人生。留下一套就好。

三、防火墙与备份

  • 防火墙（安全中心 → 防火墙和网络保护)：拦截未经许可的外来连接。开着即可；只有明确需要（如游戏联机）时才按提示放行。
  • 备份还原：设置 → 更新和安全（Win10）/系统 → 存储 → 高级存储选项（Win11）→ 备份。加一块外接硬盘，让"文件历史"自动为你备份文档。

四、账户与密码卫生

  • Microsoft 账户登录电脑：好处是同步设置与文件（OneDrive），但一定要设强密码并开两步验证。
  • 密码三不：不用生日/123456/姓名拼音；不所有网站一个密码；不把密码明文存在桌面 txt 里。
  • 推荐：密码管理器（如 Keepass / Bitwarden）+ 每站独立强密码。
⚠️ 警惕"默认登录中"的坑 用 Microsoft 账户登录 Windows 后，若邮箱/密码泄露且没开两步验证，别人云端一登就能看到你同步的文件和密码。开验证 = 加了一道门锁。

五、锁屏、PIN 与指纹

  • Win+L 一键锁屏：离开电脑必锁。
  • 设置 → 账户 → 登录选项：优先用 PIN（本地数字密码，快且只在本机有效）或指纹/人脸。
  • 开"动态锁"：手机离开蓝牙范围自动锁屏（部分版本支持），防忘锁。

六、远程控制：当心"被操作"

⚠️ 官方入口只有一个：远程桌面 Windows 自带"远程桌面"只在你主动开启时才可被连。接到"客服"电话让你装某某远程软件/输某某组织代码（TeamViewer、AnyDesk、向日葵），一律挂掉——正规售后不会远程让你输代码。
  • 需要帮家人远程装软件：用官方渠道（微信远程协助/QQ 远程）并确认对方是本人。
  • 远程桌面设置：设置 → 系统 → 远程桌面 → 开启（仅需时开启）。
🤔 课后思考 为什么说"杀毒软件管不了你手欠"？Defender 能拦病毒文件，但拦不住你主动给骗子转钱、主动输验证码。安全的第一道防线永远是人的判断。
