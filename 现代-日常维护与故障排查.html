一、原则：从软到硬、从简到繁

排查故障的正确姿势：先软件后硬件，先简单后复杂，先重启再重装。动手前先想清楚"上次正常是什么时候？这之后我做了什么？"——八成答案就在你装的软件/改的设置里。

💡 万能第一步：重启 重启会清空内存、重置所有驱动和临时状态，能解决半数"怪问题"。先重启再排查，别一上来就重装系统。

二、第一类：电脑变卡

  1. 先看占用：Ctrl+Shift+Esc 打开任务管理器 → 按 CPU/内存/磁盘排序，揪出"吃货"（如 99% 的某进程）。
  2. 瘦身启动项：任务管理器 → 启动应用，禁用一切非必需开机自启。
  3. 清存储：见 §5，磁盘满到 90% 以上会卡到崩溃。
  4. 关特效：设置 → 系统 → 关于 → 高级系统设置 → 性能设置 → 调整为最佳性能（老机器立竿见影）。
  5. 查占用大户：浏览器标签页少开；杀毒别装两套；检查是否背着挖矿脚本/占用狂。
  6. 还不行：就是硬件瓶颈了（内存小、机械盘慢）——回顾 A2-5 升级决策，SSD + 内存是性价比之王。

三、第二类：程序假死 / 无响应

  • 先干等 10 秒，Win 偶尔"缓一缓"就回来。
  • 还没动：Ctrl+Shift+Esc → 右键卡死的程序 → 结束任务（会丢未保存内容，但救回系统）。
  • 整机鼠标都转圈：Ctrl+Alt+Delete → 注销或重启；长按电源键强制关机是最后手段。
⚠️ 结束任务前的半秒 任何程序"正在保存/正在转码"时强制结束，可能损坏文件。能等就等，能保存就保存。

四、第三类：蓝屏与重启

蓝屏（BSOD）不常来，来了别慌——关键是读代码。屏幕上一行大号英文（如 MEMORY_MANAGEMENT、CRITICAL_PROCESS_DIED）就是提示：

提示关键词含义方向
MEMORY_MANAGEMENT / IRQL_NOT_LESS_OR_EQUAL内存或驱动冲突插拔内存条、更新驱动、内存检测
CRITICAL_PROCESS_DIED / KERNEL_DATA_INPAGE_ERROR系统内核异常 / 磁盘读失败查硬盘健康（CrystalDiskInfo）、重装系统
VIDEO_TDR_FAILURE显卡驱动超时重装显卡驱动
WHEA_UNCORRECTABLE_ERROR硬件级错误高概率硬件问题，过热/超频/内存老化
蓝屏＆不断重启启动失败循环进"安全模式"（开机连续重启后进恢复界面）排查或重装

记下错误码（形如 0x0000000A）去搜索："代码 + 品牌+型号" 命中率最高。⚠ 若蓝屏频繁出现，优先怀疑内存与硬盘——先跑内存检测（Windows 自带"内存诊断"）与硬盘健康检测。

五、第四类：磁盘快满了

  • 设置 → 系统 → 存储：看谁占地方，点进去逐项清理（临时文件/回收站/系统更新缓存）。
  • 磁盘清理工具：Win+R 输 cleanmgr 回车 → 选 C 盘 → 勾选"临时文件/Windows 更新清理"。
  • 大文件搬家：视频/安装包/游戏挪到 D 盘。
  • 别删 C:\Windows 里的东西，那里没你想的"垃圾"，全是系统零件。

六、预防维护清单与备份恢复

每周：磁盘整理交给系统自动；检查更新一次。
每月：清理浏览器缓存与下载文件夹；备份重要文档到另一介质。
每季：打开机箱清灰（台式机），检查风扇是否积灰打鸣。
永远：重要文件多介质备份 + 系统镜像（设置 → 系统 → 恢复 → 启动高级选项可做备份点）。
💡 断电保护 台式机插排上接个 UPS（不间断电源）或带防浪涌插排，突然断电是硬盘的隐形杀手；笔记本尽量插着电源跑大型任务。
