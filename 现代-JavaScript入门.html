一、JS 是页面的"肌肉"

HTML 摆结构、CSS 做样式，JavaScript（JS）让页面"动起来"：点击、输入、数据变化、动画、与服务器通信都靠它。本站的进度记录、测验判定、快捷键练习器、打字测试——全是 JS 写的。

二、变量与类型

let 名字 = "小明";      // 字符串（可变的量）
const 出生年 = 2008;     // 常量：不可变，通常大写
var 老写法 = 1;          // 旧语法，能不用就不用

// 常见类型
let 数字 = 42;
let 布尔 = true;         // true / false
let 数组 = [1, 2, 3];    // 一组数据
let 对象 = { 名: "小明", 年龄: 15 };
💡 命名规范 用英文+驼峰：myScore、userName，别用拼音缩写。本站代码就遵循这个风格。

三、函数

函数 = 打包一段可重复调用的动作：

function 打招呼(name) {
  return "你好，" + name + "！";
}
console.log(打招呼("小明"));  // 控制台输出：你好，小明！

// 箭头函数（现代写法）
const 加两倍 = (x) => x * 2;

四、操作 DOM

DOM = 浏览器把 HTML 变成的"元素树"。JS 通过 document 找到并修改元素：

let box = document.getElementById('myBox');  // 按 id 找元素
box.textContent = '新内容';                    // 改文字
box.style.color = '#667eea';                   // 改样式
box.classList.add('active');                   // 加一个类

五、事件：点一下就有反应

let btn = document.getElementById('goBtn');
btn.addEventListener('click', function () {
  alert('你点了我！');
});

常用事件：click（点击）、input（输入）、keydown（按键）、change（选择框变化）。本站快捷键练习器的"按了真实键"就是用 keydown 实现的。

六、控制台与调试

F12 → Console（控制台）是 JS 的"黑匣子"：

  • console.log(变量)：把值打到控制台，看程序在想什么。
  • 报错会显示红色信息+行号，点它跳到出错的代码。
  • 在控制台可以直接输入 JS 试运行（回车执行）。
⚠️ 常见翻车点 ① getElementById 找不到元素返回 null，对它操作就报错——检查 id 是否拼对；② 脚本放在 body 底部或等 DOMContentLoaded，保证元素已存在再操作。

七、动手：写一个计数器

<button id="minus">-</button>
<span id="num">0</span>
<button id="plus">+</button>

<script>
  let n = 0;
  const num = document.getElementById('num');
  document.getElementById('plus').addEventListener('click', () => {
    num.textContent = ++n;
  });
  document.getElementById('minus').addEventListener('click', () => {
    num.textContent = --n;
  });
</script>

把代码放进一个 html 文件打开，点 + / - 数字会动。恭喜，你写出了第一个有交互的程序。

本课小结

  • 变量（let/const）、函数、数组/对象是基础积木。
  • 用 document 操作 DOM，用 addEventListener 绑定事件。
  • 调试三件套：console.log、看报错行号、控制台试运行。
