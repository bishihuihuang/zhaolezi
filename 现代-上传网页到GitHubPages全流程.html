一、先了解原理

GitHub Pages 是 GitHub 提供的免费静态网页托管：把你的网页文件放进一个仓库，GitHub 就帮你在线托管一个网址。本站（静态 PWA）正是为此设计的。整体只需四步：建仓库 → 绑远程 → 推送 → 开 Pages，全程约 5 分钟。

💡 前提 本节是原理版：手动敲命令一步步推。本站的源码仓库和发布仓库都已经在本地建好并提交完毕， 你实际要做的只有「建仓库 → 双击 一键发布到GitHub.bat → 开 Pages」三步，脚本会自动帮你跑完下面的命令。 更详细的步骤见本站根目录的 发布指南.md，与本节内容一致。

二、第 0 步：确认本地状态

在 E:\上传网页\现代化\原版源文件 打开命令行（地址栏输入 cmd 回车），执行：

git log --oneline -5

能看到提交记录说明本地仓库正常，可以开始。

三、第 1 步：在 GitHub 网页新建空仓库

打开 github.com/new（需先登录，账号即你现有的 bishihuihuang）。
Repository name 填 xiandaihua（建议；换名字见"换仓库名"）。
可见性选 Public（免费账户的 GitHub Pages 需要 Public）。
不要勾选 "Add a README"、".gitignore"、"license"（本地已有，勾了会冲突）。
点 Create repository。

四、第 2 步：绑定远程并推送

回到命令行，依次执行（复制时确认是同一行）：

git remote add origin https://github.com/bishihuihuang/xiandaihua.git
git push -u origin main
  • 第一次推送会弹出 GitHub 登录窗口，按提示登录授权即可。
  • 推送成功会显示 main -> main 字样。

五、第 3 步：开启 GitHub Pages

打开仓库页面 → Settings → 左侧 Pages。
Build and deployment → Source 选 Deploy from a branch。
Branch 选 main、目录选 /(root) → Save。
本站的做法是把站点文件直接放在仓库根（GitHub 仓库本体是 上线网页/，站点就在它的根目录）， 所以这里必须选 /(root)，选成别的子文件夹线上会是 404。 选对之后线上地址是 https://你的用户名.github.io/xiandaihua/， 站内链接、sitemap、离线缓存全部不受影响。
等 1~2 分钟，刷新页面出现绿条提示后访问 https://bishihuihuang.github.io/xiandaihua/。

六、以后怎么更新

改文件 → 跑体检 → 一键发布：

node 构建工具_构建.js   # 体检必须通过（exit 0）
# 然后双击顶层的 一键发布到GitHub.bat（自动：体检 → 同步 → 提交 → 推送）
💡 更新快进技巧 脚本内部跑的就是 git add -A → git commit → git push 三连，F3 的组合拳在这里变成实战。 平时只改 原版源文件/ 里的页面，别直接改 上线网页/（每次构建会整份覆盖）。

七、常见报错对照

报错关键词原因解决
rejected ... fetch first远程有本地没有的提交（如网页上勾了 README）git pull --rebase origin main 后重推
Authentication failed登录凭据过期控制面板→凭据管理器→Windows 凭据→删除 git:https://github.com 条目后重推
Could not resolve host网络不通 / 代理问题检查网络或关闭代理后重试
Pages 打开 404分支/目录选错，或未等部署完成Settings→Pages 确认 main + /(root)，等 2 分钟
页面样式丢失通过 file:// 双击打开正常现象；用线上地址访问
更新后没变化Service Worker 缓存等 1 分钟后普通刷新（新 SW 自动接管），或 Ctrl+F5 强刷一次

八、换仓库名 & 关于隐私

换仓库名：如果第 1 步用了别的名字（如 learn-modern）：① 把 构建工具_构建.js 顶部 const REPO = 'xiandaihua'; 改成新名字；② 顶层 一键发布到GitHub.bat 里的 set "REPO=..." 也改掉；③ 重新跑 node 构建工具_构建.js（sitemap/robots 网址全部更新）；④ 删除旧的 GitHub 仓库并新建同名的，再双击脚本重推。

⚠️ 隐私提醒 推送到 Public 仓库的内容全网可见。本站不含任何密钥、密码或个人信息；git log 中的提交邮箱是 git 全局配置的邮箱（GitHub 会显示在提交记录里），介意的话可执行 git config user.email "你的GitHub用户名@users.noreply.github.com" 后再提交。
