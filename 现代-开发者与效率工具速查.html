一、命令行常用快捷键（Windows 终端）

快捷键作用说明
Win + R → 输入 cmd打开命令行或 Win+X → 终端
↑ / ↓上/下一条历史命令重敲命令的神器
Tab自动补全文件名 / 命令按两次 Tab 浏览候选
Ctrl + C终止当前正在跑的命令命令卡死按它
Ctrl + V粘贴终端里也可以按 Shift+Insert
Ctrl + A光标移到行首Ctrl+E 到行尾
Ctrl + L清屏等于输入 cls

二、代码编辑器（VSCode 等）

快捷键作用说明
Ctrl + P快速打开文件模糊搜索文件名，秒开
Ctrl + F当前文件查找Ctrl+H 查找替换
Ctrl + Shift + F整个项目查找—
Ctrl + /注释 / 取消注释新手必学第一招
Ctrl + D选中下一个相同词连续按可多光标批量改
Ctrl + S保存强迫症福音
Ctrl + `打开内置终端写码跑命令无缝切换
Ctrl + Enter光标位置换行不用跑到行尾

三、F12 开发者工具

快捷键作用说明
F12开/关开发者工具模块G 的调试都靠它
Ctrl + Shift + C选取网页元素鼠标点哪看哪的代码
Ctrl + F在调试面板内查找—
Esc呼出/收起控制台面板—
面板内 Ctrl + `切换控制台—

四、系统效率工具

快捷键作用说明
Win + V剪贴板历史不只复制一条，可回看最近 20+ 条
Win + Tab任务视图可新建"虚拟桌面"分工作区
Ctrl + Win + D新建虚拟桌面Ctrl+Win+F4 关闭当前
Ctrl + Shift + Esc任务管理器看哪个程序吃内存，可强制结束
Win + Shift + S区域截图截图自动进剪贴板，Ctrl+V 即用
Win + G游戏栏（录屏）录制屏幕 / 截图
Win + K无线投射投到电视 / 第二屏
