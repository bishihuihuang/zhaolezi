一、主板：一切零件的家

主板（Motherboard）是一块大电路板，CPU、内存、硬盘、显卡全部插在它上面，零件之间通过主板上的线路交换数据。买电脑不必精通主板，但要知道：主板决定了能装什么型号的 CPU 和内存（即"兼容性"）。

芯片组主板上的"交通调度中心"，决定支持哪代 CPU、几个硬盘位
插槽CPU 插槽、内存插槽（一般 2-4 条）、显卡 PCIe 插槽
接口后面板上的 USB、网口、音频口都焊在主板上

二、CPU：执行每一条指令

CPU（中央处理器）负责执行程序里的每一条指令，是"干活速度"的决定者之一。它不断地做三件事：取指令 → 翻译 → 执行，每秒循环几十亿次。第 2 课说的"存储程序"思想就在这里落地：程序存在内存里，CPU 逐条取出执行。

📜 取指令→ 🔍 翻译解码→ ⚙️ 执行运算→ 💾 写回结果↺

三、看懂 CPU 的四个数字

指标含义通俗理解
主频（GHz）每秒多少个"节拍"，如 3.6GHz≈每秒 36 亿拍一个人手速多快
核心数同时独立干活的"小脑"数量，常见 4-16 核几个工人同时干活
线程数每个核心可拆成 2 个虚拟通道（超线程）工人左右手同时开工
缓存（MB）CPU 旁边的超高速小内存手边的小工具盒
🌡 顺带认识"核显" 很多 CPU 内置了显示芯片（集成显卡/核显），不装独立显卡也能亮机。办公、看视频、轻度游戏足够；大型游戏和视频渲染才需要独显（见 A2-4）。

四、品牌与定位：i5/R5 够用吗

常见品牌：Intel（酷睿 i3/i5/i7/i9）与 AMD（锐龙 R3/R5/R7/R9）。数字越大定位越高，但跨代比较不能只看数字（如 i5-13400 强于老 i7-7700）。

定位典型型号适合场景
入门i3 / R3上网、文档、网课
主流i5 / R5办公、编程、主流网游——大多数人的甜点位
高性能i7 / R7视频剪辑、虚拟机、大型游戏
旗舰i9 / R9重度创作、AI 训练、工作站

本页小结

  • 主板决定兼容性；CPU 循环"取指-译码-执行"，是电脑的大脑。
  • 看 CPU 先看四件套：主频、核心、线程、缓存。
  • 选型看用途：主流用户 i5/R5 足够，别为用不到的性能买单。
