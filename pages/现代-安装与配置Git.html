安装与配置 Git

一、下载安装 Git

打开 Git 官网 git-scm.com，点击 Windows 下的 "Download"，下载 64-bit 安装包。
双击安装，一路 "Next"；注意勾选 "Add Git Bash Profile to Windows Terminal"（如果有），其余选项保持默认即可。
安装完成，开始菜单会出现 Git Bash 和 Git GUI。Windows 10 以上系统通常也可直接在任意文件夹右键选择 "Open Git Bash here"。
💡 本站建议 作者用的是 git 2.55（Windows 版）。版本号差别不影响本模块任何命令，保持默认安装即可，不需要纠结最新版。

二、认识 Git Bash

Git Bash 是 Git 自带的命令行终端，风格像 Linux 的 bash：

Administrator@DESKTOP MINGW64 ~
$ █   ← 在 $ 后面输入命令，回车执行
  • cd 文件夹名 进入目录；ls 列出文件；pwd 显示当前位置。
  • 在资源管理器空白处右键选 "Git Bash Here"，就直接在该文件夹打开终端——最常用。
  • 粘贴用 Ctrl+V 或 Shift+Insert；命令卡死按 Ctrl+C 终止。

三、验证安装

打开 Git Bash，输入下面命令查看版本——能输出版本号说明安装成功：

git --version
# 输出示例：git version 2.55.0.windows.1

四、设置用户名与邮箱

Git 提交时会记下"谁做的这次提交"，所以必须先设置你的名字和邮箱。邮箱建议用注册 GitHub 时同一个邮箱：

git config --global user.name "bishihuihuang"
git config --global user.email "你的邮箱@example.com"
⚠️ 照抄会踩坑 上面是示例，请把名字和邮箱换成你自己的（GitHub 用户名 + 注册邮箱）。不设置的话，第一次 commit 会报错："Please tell me who you are"。

五、检查配置

git config --list        # 列出全部配置
git config user.name     # 只查看用户名
git config user.email    # 只查看邮箱

如果显示的名字/邮箱不对，重跑一次 --global 命令覆盖即可。

六、配置的三个级别

级别作用范围命令
--system整台电脑所有用户（很少用）git config --system
--global当前用户所有仓库（推荐，配置一次全适用）git config --global
（不加）仅当前仓库git config user.name ...

本课小结

  • 官网下载安装 Git，全程默认选项即可；Git Bash 是常用终端。
  • git --version 验证安装；git config --global 设置用户名和邮箱（务必换成自己的）。
  • 配置分 system / global / 当前仓库三级，日常用 --global。
