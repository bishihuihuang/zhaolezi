一、网页的骨架：三件套

技术类比负责什么文件后缀
HTML骨架 / 结构标题、段落、按钮、图片这些"内容元素".html
CSS皮肤 / 样式颜色、字体、大小、间距、布局"长得好看".css
JavaScript肌肉 / 行为点击、弹窗、数据变化、动画等"互动".js
HTML
（有什么）+ CSS
（长什么样）+ JS
（能干什么）= 网页

你正在看的本站就是三件套写出来的：页面结构是 HTML，渐变背景和卡片样式是 CSS，模块树、进度、测验都是 JavaScript。

二、浏览器是怎么把代码变成页面的

  1. 请求：你输入网址，浏览器向服务器要回 HTML 文件。
  2. 解析：浏览器把 HTML 读成结构树（DOM），遇到 <link> 再拉 CSS，遇到 <script> 再拉 JS。
  3. 渲染：按 CSS 规则画出来；JS 运行后还能改结构、改样式、响应你的点击。
💡 本站就是例子 打开本站任选一课，按 F12 切到 Elements 面板，就能看到页面真实的 DOM 结构——这正是 G5 的预习。

三、需要什么工具

  • 编辑器：VS Code（免费、最主流）或记事本也够用起步。装个中文界面/自动补全插件体验更好。
  • 浏览器：Chrome / Edge 都行，F12 开发者工具是调试利器。
  • 本地服务器（进阶）：用 VS Code 的 Live Server 插件，能即时预览改动（本站纯静态也能直接双击打开）。

四、文件怎么组织

my-site/
├── index.html      ← 入口页（网页必须有它）
├── style.css       ← 样式
├── script.js       ← 行为
└── images/         ← 图片文件夹

规则很简单：一个页面一个 .html，公共样式/脚本拆出来共用一个 .css / .js。本站就是这么组织的——每个模块一课一个 html，公共样式都在 common.css。

五、第一个"能打开的网页"

新建一个 index.html，粘贴下面内容，双击用浏览器打开：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>你好，世界！</h1>
  <p>这是我写的第一行网页。</p>
</body>
</html>
💡 看到了什么 <h1> 是大标题，<p> 是段落，<meta charset="UTF-8"> 保证中文不乱码（A4 那课提过）。下一课 G2 逐个讲这些标签。

本课小结

  • 三件套：HTML 结构、CSS 样式、JS 行为。
  • 浏览器：请求 → 解析 → 渲染，JS 还能动态改页面。
  • 工具：VS Code + 浏览器即可；一个页面一个 html，公共样式拆出来。
