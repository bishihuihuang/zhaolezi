一、网址的两副面孔

一台服务器在网上的"真地址"是 IP（一串数字，如 142.250.66.238），但人记数字费劲——于是有了域名（如 google.com）。你输 www.baidu.com，浏览器需要先把它"翻译"成某台服务器的 IP，这活儿归 DNS（域名系统）。

二、IP 家族：v4 与 v6、公网与内网

类别说明示例
IPv432 位，约 43 亿个，已枯竭，大量靠 NAT 复用223.5.5.5
IPv6128 位，几乎取之不尽的"新一代地址"240e:390:2a00:…
公网 IP全球唯一，可直接被访问（服务器用它）120.xx.xx.xx
内网 IP私有网段，只在局域网内有效（你家设备）192.168.1.5

三、域名结构：从右往左读

以 www.baidu.com 为例，从右往左一层层缩小范围：

www . baidu . com
│      │      └── 顶级域（.com 商业 / .cn 中国 / .org 组织）
│      └───────── 主域名（b站注册的一级域名）
└──────────────── 子域名（该站的"接待入口"；常是 www 或 空）

顶级域还有 .net、.edu（教育）、.gov（政府）、.io/.dev（开发者爱用）等。主域名注册要向域名商付费租用，一年几十到几百元不等。

四、DNS：全球电话簿

全球有无数台 DNS 服务器层层协作，把"名字"翻译成"号码"。你查一次 www.baidu.com 大致流程：

  1. 本地 DNS 缓存（浏览器/系统里存过的结果）先找，命中直接用。
  2. 没命中 → 问运营商/公共 DNS（如 223.5.5.5）。
  3. 它再层层问根服务器 → 顶级域服务器 → 该域名的权威服务器，拿到 IP 返回给你。
  4. 你带着 IP 去访问网站（C3 讲这一步）。
💡 为什么换 DNS 能"变快/能上了"？ 运营商 DNS 偶尔慢/缓存陈旧/解析异常，换成大厂公共 DNS（阿里 223.5.5.5、腾讯 119.29.29.29、Cloudflare 1.1.1.1）往往立竿见影——电话簿换成了"全国联网版"。具体改法见 B5。

五、解析慢/失败怎么办

  • 网页"找不到服务器/无法访问此网站"，先确认：其他网站能上吗？能=问题可能在这站或 DNS。
  • 清 DNS 缓存：Win+R → cmd → ipconfig /flushdns。
  • 换公共 DNS（见上）。
  • 还不行：可能是那个网站自己的服务器挂了——换个时间再试，或用"网站状态检测"网站确认。

六、自己动手查地址

// 命令行工具（Win+R 输 cmd）
nslookup baidu.com      ← 查域名对应的 IP
ping baidu.com          ← 测试连通性与延迟

// 在浏览器输 IP 直接访问服务器？（大部分网站 443 默认端口，浏览器会尝试）
