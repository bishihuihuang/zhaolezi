浏览器与文本编辑速查

D2-2 · 快捷键速查库 | 上网冲浪与打字编辑的效率核心

🔎 怎么查 表格支持搜索，输入关键词（如"标签页""全选"）即时过滤。浏览器快捷键以 Chrome / Edge 为准，其他浏览器大同小异。

一、浏览器：标签页与窗口

快捷键作用说明
Ctrl + T新开标签页并自动聚焦地址栏
Ctrl + W关闭当前标签页关错了按 Ctrl+Shift+T 找回
Ctrl + Shift + T恢复刚关闭的标签页可连续恢复多个
Ctrl + Tab切换到下一个标签页Ctrl+Shift+Tab 往回切
Ctrl + 1-9跳到第 N 个标签页9 跳到最后一个
Ctrl + Shift + N打开无痕窗口不记录浏览历史
Ctrl + N新开一个窗口—
Ctrl + H打开历史记录—
Ctrl + J打开下载列表—
F5 / Ctrl + R刷新当前页Ctrl+F5 强制刷新（清缓存）
F12打开开发者工具网页调试，模块G 会教
Esc停止加载 / 关闭弹层—

二、浏览器：地址栏与页面

快捷键作用说明
Ctrl + L聚焦地址栏输入网址或搜索词直达
Ctrl + D收藏当前页—
Ctrl + F页内查找本页表格搜索就是这么做的
Ctrl + S保存网页—
Ctrl + P打印 / 另存 PDF存 PDF 选"另存为 PDF"
Ctrl + +/-页面放大 / 缩小Ctrl+0 恢复 100%
空格向下翻一屏Shift+空格 向上翻
Home / End回到页首 / 页尾—

三、文本编辑：编辑全家桶

快捷键作用说明
Ctrl + C复制Windows 下也支持直接按 Ctrl+Insert
Ctrl + V粘贴Ctrl+Shift+V 粘贴纯文本（去格式）
Ctrl + X剪切复制 + 删除原内容
Ctrl + Z撤销Ctrl+Y 重做（部分软件用 Ctrl+Shift+Z）
Ctrl + A全选—
Ctrl + B加粗—
Ctrl + I斜体—
Ctrl + U下划线—
Delete删除光标后一个字符Backspace 删除前一个
Ctrl + Delete删除后一个单词Ctrl+Backspace 删除前一个单词

四、文本编辑：光标移动与选中

快捷键作用说明
Home / End光标到行首 / 行尾—
Ctrl + ←/→按单词跳光标比逐字移动快一个量级
Ctrl + ↑/↓按段落移动（多数编辑器）—
Shift + 方向键逐字选中—
Shift + Home/End选中到行首 / 行尾—
Ctrl + Shift + ←/→按单词选中选词神器
Ctrl + Shift + Home/End选中到文首 / 文尾—
三击鼠标选中整段双击选中单词
💡 记忆法 编辑区的规律一句话：Ctrl = 按词/整行级，Shift = 选中，Home/End = 行首尾。这套规律同样适用于 Word、微信聊天框、代码编辑器，练一次到处受益。
