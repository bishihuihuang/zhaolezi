一、标签语法

HTML 由标签（Tag）组成。绝大多数标签成对出现：开始标签 + 内容 + 结束标签：

<p>这是一段文字。</p>      ← 段落标签
<h1>大标题</h1>            ← 一级标题
<img src="a.png" alt="图">  ← 自闭合标签：没有结束标签，用属性给信息
  • 结束标签在名字前加 /；标签可以嵌套（<p><b>加粗</b></p>）。
  • 标签名不区分大小写，但惯例用小写。

二、文档骨架

<!DOCTYPE html>                 ← 声明这是 HTML5
<html lang="zh-CN">              ← 根元素，lang 声明语言
  <head>                         ← 头部：页面"元信息"（不显示在页面里）
    <meta charset="UTF-8">      ← 编码，中文不乱码的关键
    <title>网页标题</title>      ← 浏览器标签页上的名字
  </head>
  <body>                         ← 主体：页面上能看到的所有内容
    <h1>你好</h1>
  </body>
</html>

三、常用标签

标签作用
<h1>~<h6>标题，h1 最大；一页通常只用一个 h1
<p>段落
<a href="...">超链接（点它跳转）
<img src="..." alt="...">图片，alt 是图片加载失败时/读屏软件读的文字
<ul><li>无序列表（圆点）
<ol><li>有序列表（数字）
<strong> / <em>强调（粗体）/ 斜体
<br>换行（自闭合）
<div> / <span>无意义的"容器"，用来包住内容好加样式

四、属性和链接

属性写在开始标签里，格式 属性名="值"。最常用的是 href（链接目标）和 src（资源地址）：

<a href="https://github.com" target="_blank">打开 GitHub 新窗口</a>
<a href="page2.html">本站内部页面跳转</a>
<img src="images/me.png" alt="我的照片" width="200">
💡 绝对 vs 相对路径 https://.../xxx.png 是绝对路径（完整网址）；images/me.png 是相对路径（相对当前文件位置）。做自己的站点基本都用相对路径，换域名不用改。

五、列表、表格与表单

<!-- 有序列表 -->
<ol>
  <li>第一步</li>
  <li>第二步</li>
</ol>

<!-- 表格 -->
<table>
  <tr><th>科目</th><th>分数</th></tr>
  <tr><td>语文</td><td>95</td></tr>
</table>

<!-- 表单（按钮） -->
<button onclick="alert('你好！')">点我</button>

表格的 tr 是行、th 是表头、td 是单元格。本站的速查表（D2 系列）就是这么写的，按 F12 就能看到。

六、语义化

用"有意义"的标签而不是清一色 <div>：<header>（页头）、<nav>（导航）、<main>（主体）、<footer>（页脚）。好处：搜索引擎更懂你的页面，读屏软件更好用，代码更易读。

七、新手常见错误

错误后果修法
忘记写 <meta charset="UTF-8">中文乱码head 里补上
结束标签漏写 /结构错乱、样式错位养成标签成对写再填内容
嵌套交叉 <b><i>..</b></i>浏览器自动"猜"结构先关内层再关外层
图片 src 写错路径显示裂图用相对路径并核对文件名/大小写

本课小结

  • HTML=结构；标签成对、可嵌套，属性写在开始标签。
  • 骨架：DOCTYPE → html → head（meta/title）+ body。
  • 常用标签练熟：h1~h6/p/a/img/ul/ol/table/button；多用语义化标签。
