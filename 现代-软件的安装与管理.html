一、下载：只认官网与官方商店

  • 官网最安全：搜"腾讯 官网""微信 官网"之类，认准域名（如 weixin.qq.com）。
  • 微软商店（Microsoft Store）：Windows 自带的官方应用商店，里面的应用经过审核、自动更新，最省心。
  • 警惕：第三方"软件园/高速下载"站下载的安装包，十有八九捆绑全家桶——不要用"搜索软件下载"的第一条广告链接。
⚠️ 一眼识破 官网下载页常有一堆醒目的绿色"高速下载"按钮——真正的下载链接往往藏在页面下方"下载：Windows 版"小字里。认准网址和文件后缀（.exe 安装包 / .msi）再点。

二、安装向导：三个坑点要看清

双击安装包后进入向导，新手最常踩三处：

  1. 附加组件：勾选项"安装XX浏览器""体验新功能"——全部取消勾选。
  2. 安装目录：默认 C 盘没问题，但想轻装可改到 D:\Software 下（见 §3）。
  3. "快速安装" vs "自定义安装"：永远选自定义，才看得到上面两处选项。

三、安装目录选在哪

情形建议
常用小软件（微信、QQ）默认 C 盘即可，方便 & 更新省心
大型软件（游戏、剪辑、建模）装到 D 盘等非系统盘，C 盘瘦身、重装系统不心疼
绿色软件（免安装版）解压到固定文件夹即可用，不写注册表

四、反悔了？正确卸载

  1. 设置 → 应用 → 已安装的应用，找到目标 → 卸载（Win11 路径）。
  2. 或控制面板 → 卸载程序 → 右键卸载。
  3. 懒人捷径：开始菜单右键程序 → 卸载。
💡 卸不干净怎么办 正常卸载后，残留可能藏在 C:\Users\用户名\AppData 和 Program Files 目录里。手动删残留有风险（删错会坏别的软件）；新手用系统自带卸载即可，别急着上"强力卸载工具"。

五、防捆绑：让广告协议失效

  • 安装时逐页看：每一页别直接"下一步"，注意复选框。
  • 发现被装了一堆"XX桌面/XX电脑管家"：第一时间去 §4 卸载，越早越干净。
  • 装完新的浏览器，夺回默认程序：设置 → 应用 → 默认应用 → 把浏览器/播放器改回你熟悉的那款。
  • 被"不能关的弹窗"骚扰：任务管理器 → 启动应用 → 禁用它。
💡 一句话心法 任何网址/弹窗让你"点这里下载"，先想一个问题：这软件我要不要？从哪能拿到官方版？想清楚再点。

六、更新与"绿色软件"

  • 该更就更：软件更新往往补安全漏洞。但大版本（Win11 周年更新、游戏客户端大更）可稍等一周，看评测再更。
  • 绿色软件：免安装、直接解压运行，U盘都能带。但来源要更谨慎（易被改打包），仅认口碑好的工具站/官方 GitHub Releases。
  • 杀毒软件：Windows 自带 Defender 已够用于普通用户；装多个杀毒反而互相打架拖慢电脑。
🤔 课后思考 为什么"国产软件全家桶"那么难卸干净？回想 B2 的文件系统——安装时它们把文件写进了 C:\Program Files、写了注册表、设了开机自启、还改了默认浏览器。层层叠叠，卸起来当然费劲。这就是懂原理的价值：安装时的每个选择，都在为未来买单。
