## 0. 文档说明

**目的**：为 zhaolezi
全站建立一套可验收的全面测试基线，覆盖美观与功能两大维度，外加性能、可访问性、SEO、兼容性、安全等硬性指标，以及防回归机制验证。本清单经用户确认后，才按清单执行测试。

**范围**：线上站点 https://bishihuihuang.github.io/zhaolezi/
全部页面。交接文档口径为 42 页（1-40 + index +
文件搜索），本次实测发现根目录另有
41.html（看看作业），是否纳入管理范围需用户确认。测试对象以线上站点真实体验为准，本地代码仅作质量审查参照。

**依据**：历史交接文档（V1.9.3\~V1.9.5
可读性审计与防回归机制落地记录）、《主题可读性防回归规范.md》、线上站点实测（2026-10-02，本机
Chrome + CDP 驱动）、代码质量静态审查（theme.js / zl-features.js /
common.css / service-worker.js / \_混淆工具.js）。

**优先级定义**：

- **P0**：阻断项------不修复则影响核心可用性/发布，或为已确认缺陷。

- **P1**：重要项------影响体验或存在明确风险，应在近期覆盖。

- **P2**：优化项------锦上添花或低风险改进建议。

**测试环境备注**：本清单所有实测基线基于本机 Chrome（Windows，无 AVX2
CPU，headless+CDP）；线上为 GitHub Pages（境外
CDN），性能数据受网络链路影响，需多次复测取中位值。
